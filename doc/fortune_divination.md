# Xiaozhi ESP32 今日占卜功能详细说明

本文档详细梳理了 AI 罗盘中“今日占卜”跑马灯特效的完整处理逻辑与交互机制。

## 1. 触发占卜 (Trigger)
有两种方式可以进入“今日占卜”：
- **触摸触发**：在屏幕中心（太极图区域）**持续按住 3 秒**。刚按下时屏幕中间会轻量化提示“今日占卜 继续按住…”，满 3 秒后正式启动。
- **按键触发**：长按设备侧边的 **Boot 按键 3 秒**。

## 2. 跑马灯动画过程 (Animating)
触发后，会立刻关闭文字提示，进入跑马灯阶段：
- **视觉效果**：12 个功能图标以 **每 25 毫秒（0.025秒）** 的速度依次被点亮。当前点亮的图标会放大并变成 **青色 (Cyan)**，未点亮的图标保持正常的 **全金色 (Gold)**。
- **听觉效果**：每一次图标高亮切换时，都会伴随一次清脆的 `POPUP`（步进）音效。
- **基础时长**：如果不进行额外操作，跑马灯动画默认会持续运行 **15 秒**。

## 3. 互动与时间延长 (Interactive Hold)
跑马灯带有“按住延长”的交互机制，提升把玩体验：
- **无限期跑马灯**：如果是通过“触摸按住太极”触发的，只要手指**一直不松开**，跑马灯就会无限期持续转动下去。
- **松手倒计时**：当手指离开太极区域后，系统会启动一个 **5 秒** 的收尾倒计时。跑马灯会在松手后的 5 秒钟刚好停止，落定在最终结果上。

## 4. 占卜结果展示 (Result)
当跑马灯时间到达（基础的 15 秒结束，或松手后的 5 秒结束）：
- **落定目标**：动画会正好停在系统一开始随机选中的那个功能图标上。
- **视觉定格**：被选中的图标保持放大和青色高亮，其他图标为金色。
- **音效一致**：最后一刻**不会**播放特殊的成功音效，而是保持和跑马灯一致的 `POPUP` 音效，做到听觉上的连贯与统一。
- **显示内容**：太极中心会弹出该功能对应的详细文案信息（复用调试信息卡片 UI 进行轻量化展示）。

## 5. 退出与重新占卜 (Reset & Retrigger)
当占卜结果展示在屏幕上时，用户可以进行以下操作：
- **退出结果**：短按一下 **Boot 键** 或 **电源键**，即可关闭结果卡片，图标恢复默认全金，回到罗盘的初始待机（Idle）状态。
- **直接重抽**：如果不想按键退出，可以直接再次 **长按太极区域 3 秒** 或者 **长按 Boot 键 3 秒**，系统会自动清理当前结果并无缝开启下一轮跑马灯占卜。
